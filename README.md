# ODAAT

Reflexiones diarias para acompañar cada día con una pausa, una lectura y un momento de reflexión.

ODAAT ofrece una reflexión diferente para cada día del año y permite consultar también una reflexión al azar.

## Funcionalidades

- Reflexión del día.
- Reflexión aleatoria.
- Consulta de las reflexiones disponibles.
- Interfaz web sencilla y accesible.

## Enlaces

- **Aplicación:** [odaat.cuevaneander.tech](https://odaat.cuevaneander.tech)

## Tecnología

- Astro
- FastAPI
- Python

## Fuente

Las reflexiones proceden de [Alcohólicos Anónimos](https://www.aa.org/es/daily-reflections).
